# Proyecto Parcial 1 - Componentización

Componente web `<tarjeta-producto>` desarrollado con HTML5, CSS3 y JavaScript
vanilla utilizando Web Components para la asignatura Desarrollo de
Aplicaciones Web y Sistemas Operativos (193308), UFPSO.

## Estructura

```text
proyecto-parcial1/
├── index.html
├── README.md
├── css/
│   └── styles.css
├── js/
│   ├── tarjeta-producto.js
│   └── main.js
└── assets/
```

## Tecnologías

- HTML5
- CSS3
- JavaScript ES6+
- Web Components
- Custom Elements
- Shadow DOM
- Git y GitHub
- Visual Studio Code
- Live Server

## Funcionalidades

- Tres tarjetas de producto reutilizables.
- Atributos `imagen`, `titulo`, `descripcion` y `precio`.
- Precio formateado en pesos colombianos.
- Botón "Agregar al carrito".
- Evento personalizado `agregar-al-carrito`.
- Contador del carrito.
- Diseño responsive con CSS Grid.
- Estilos encapsulados mediante Shadow DOM.

## Cómo ejecutarlo

1. Abrir la carpeta en Visual Studio Code.
2. Instalar la extensión Live Server.
3. Abrir `index.html`.
4. Clic derecho sobre `index.html`.
5. Seleccionar **Open with Live Server**.
